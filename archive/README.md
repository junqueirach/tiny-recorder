# Archive

Earlier versions, kept on purpose. Each folder in `versions/` holds the app's Python modules and icon at that version (`tinyrecorder_v0.1.0.py` and its modules, and so on), so you can follow how the tool grew. To run one, copy its folder next to a `requirements.txt` environment and start the `tinyrecorder_v*.py` file. The current version is in the repository root (`tinyrecorder.py`).

The archive keeps the code only; the tests of each version are not kept.
